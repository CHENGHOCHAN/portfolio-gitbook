### 核心概念

故事發生在一顆曾擁有高度科技文明、卻因資源戰爭而沒落的星球。戰爭留下的自動化兵器「泰坦巨人」仍在各地活動並破壞生態。

玩家扮演持有傳送寶石的旅行者，穿越遺跡、解開機關並躲避巨人威脅，逐步接近旅程終點。

### 設計支柱

1. **尺度與孤獨感**：以旅行者與泰坦巨人的巨大比例差，建立壓迫、遼闊與孤身前進的感受。
2. **觀察優先**：玩家先閱讀地形、巨人行為與機關，再選擇逃脫或反制路線。
3. **自然世界的觸感**：透過風場、植被擺動、材質腳步聲與碰撞音效提升沉浸感。
