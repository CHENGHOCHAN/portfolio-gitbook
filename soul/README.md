### 核心概念

玩家扮演被囚禁在邊境監獄的不死者，因獲得帝國之主的靈魂碎片而掙脫枷鎖。遊戲以生命與精力管理、雙手武器、翻滾閃避、鎖定與死亡學習建立硬核戰鬥。

### 設計支柱

1. **挑戰與學習**：玩家從失敗中理解敵人節奏，而不是依靠無限制輸出。
2. **黑暗異域世界**：以監獄、火葬祭台、巨門與空降平台建立荒涼、孤獨與神祕感。
3. **靈魂碎片敘事**：能力成長、主角命運與三族衝突都圍繞碎片展開。
