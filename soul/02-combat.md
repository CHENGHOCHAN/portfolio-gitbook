# 02 · 戰鬥系統設計

### 核心資源

* **生命（HP）**：歸零時角色死亡並顯示 YOU DEAD。
* **精力（Stamina）**：攻擊、翻滾與奔跑會消耗精力，玩家必須保留資源應對下一次攻擊。

### 基本操作

| 功能        | 操作方向    |
| --------- | ------- |
| 移動        | W／A／S／D |
| 左手武器攻擊／確定 | 滑鼠左鍵    |
| 右手武器攻擊    | 滑鼠右鍵    |
| 目標鎖定      | 滑鼠滾輪    |
| 翻滾閃避      | Space   |
| 使用道具      | R       |
| 地圖        | M       |
| 選項        | Esc     |

### 死亡與重生

死亡後可以重生，但必須付出代價。玩家也可以使用「死亡骷髏」返回最近的葬堆存檔點。死亡畫面以紅色 YOU DEAD 清楚結束當次嘗試，讓玩家重新調整策略。

### 關鍵道具

* **恢復藥水**：恢復生命值。
* **靈魂碎片**：使角色恢復至完整狀態，並連結主線世界觀。
* **死亡骷髏**：傳送回最近的葬堆。
* **騎士證明**：內含傳訊功能，用於召喚帝國飛船。

### Boss 與戰鬥目標

監獄長是逃離邊境監獄的主要阻礙。戰鬥重點是閱讀攻擊前搖、管理精力、選擇左右手武器並在安全窗口攻擊；不使用未經現有版本證實的精確反擊秒數、倍率或三階段數值。

### UI 資訊

HUD 顯示生命、精力、玩家頭像、左右手武器、裝備道具與異域幣。功能選單包含裝備、背包、地圖與系統設定。
