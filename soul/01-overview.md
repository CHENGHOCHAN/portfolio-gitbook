# 01 · 遊戲概述

### 世界觀

故事發生在「異域」大陸。神族統治被人族、鬼族與龍族組成的聯盟推翻後，人族帝國掌握大部分領土，引發其他兩族不滿。帝國之主遭到刺殺，身軀化為具有力量的靈魂碎片並散落各地。

### 劇情開端

主角是受到詛咒、被關押在邊境監獄的不死者。他意外取得一塊靈魂碎片後掙脫枷鎖，並在大魔法師梅林協助下於地牢中甦醒。

玩家必須穿越監獄、擊敗監獄長、取得騎士證明，再召喚帝國飛船離開。長期目標是收集大陸各地的靈魂碎片，使自身恢復完整並重新整合紛亂的異域。

### 核心循環

探索地牢 → 鎖定敵人 → 管理生命與精力 → 攻擊／翻滾／使用道具 → 死亡並學習 → 擊敗守衛與取得碎片 → 開啟逃離路線

### 主要場景

* 主角牢房與監獄走廊
* 地牢下水道與中央木橋
* 火葬祭台／葬堆存檔點
* 雙層建築與大廳二樓
* 監獄巨門
* 雲層上的地牢空降平台與監獄長戰鬥區
