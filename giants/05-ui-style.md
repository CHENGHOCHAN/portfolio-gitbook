# 05 · UI 視覺規範

### 設計目標

介面以不遮擋場景與維持探索沉浸感為方向，並配合遊戲 LOGO、主選單、教學提示與遊戲內資訊完成基本操作引導。

### 已完成內容

* 遊戲 LOGO 草稿與確定稿
* 主選單與功能選項
* 教學關卡提示
* 遊戲內介面版本
* 封面、PV 與展示所需的視覺識別

### 使用原則

1. 場景與地標優先承擔方向引導。
2. 只有操作或狀態無法由環境清楚傳達時才顯示提示。
3. UI 文字、按鍵與圖示需要在實機畫面中保持清楚，不與背景融為一體。
4. LOGO 與選單延續自然世界、遺跡和科技文明殘骸的視覺語言。

本頁不使用未被現有 UI 素材支持的固定色票、指定字體、斗篷血量狀態與版本測試數據。
