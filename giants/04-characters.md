# 04 · 角色設計

### 旅行者

| 屬性   | 設定                |
| ---- | ----------------- |
| 性別   | 男性                |
| 身高   | 約 170 公分          |
| 身分   | 環遊星球、尋找傳送門的旅行者    |
| 核心道具 | 傳送寶石              |
| 視覺特徵 | 旅行服裝、披風／圍巾、皮革裝備與劍 |

旅行者幼年意外取得傳送寶石，因而擁有使用各地傳送門的權限。角色造型以長途旅行所需的輕便、防護與磨損感為主要方向。

### 泰坦巨人

巨人與主角比例約為 10：1，是昔日資源戰爭留下的自動化大型作戰兵器。它們不是自然誕生的神祕種族，而是文明崩潰後仍持續運作的戰爭遺產。

#### 石巨人

第一張地圖的重要威脅，造型以岩石、重型結構與遺跡感建立沉重壓迫。

#### 浮空巨人

具有飛行系統與金屬質感，是星球傳說中的特殊泰坦兵器。

### 尺度意圖

巨大比例先建立壓迫，再讓玩家透過觀察巨人動作與場地找到安全路線。角色設計服務的是「渺小旅行者面對戰爭遺產」的核心對比。
