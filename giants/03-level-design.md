# 03 · 關卡設計

### 關卡設計方向

關卡以「看見目標、理解障礙、找到機關、完成移動」為基本節奏。道路、光源、遺跡輪廓與高度差共同取代過度依賴 UI 箭頭的引導。

### 主要區域

#### 遺跡與草原區

利用開闊景觀建立世界尺度，再逐步加入石橋、坡道、尖刺與彈跳板，讓玩家學習環境互動。

#### 第二場景與機關區

提高機關密度，加入壓力板、地圖轉場、怪物與更複雜的跑酷路線，要求玩家綜合使用前面學到的判讀方式。

#### 四季浮島

由多座空島構成，以櫻花、沼澤樹與白杉木等不同植被色彩區分區域。此處是傳送寶石所記載的最後傳送門所在地，也是最終巨人與跑酷挑戰的舞台。

### 製作流程

概念與故事 → 地圖輪廓／平面圖 → 關卡建模 → 機關與轉場整合 → 場景美術 → 實機測試與修正

本文件不使用未被開發紀錄支持的完成率、首殺率與測試百分比。
